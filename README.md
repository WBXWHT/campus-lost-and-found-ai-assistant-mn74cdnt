# campus-lost-and-found-ai-assistant

校园失物招领AI助手，基于RAG实现智能查询匹配

项目经历：我曾主导“校园失物招领AI助手”项目，旨在解决校内信息匹配效率低的问题。我基于Coze平台搭建了智能对话机器人，结合RAG技术接入校内论坛数据库，实现自然语言查询与精准匹配。项目上线后，平台日均处理查询量提升3倍，用户找回失物的平均耗时从48小时缩短至15小时，用户满意度达92%。通过该实践，我深入掌握了AI工具落地、效果数据分析及迭代优化的全流程。

## 运行
```bash
pip install -r requirements.txt
python main.py
```
